# Design Guidelines

This project follows the visual design specified in `designs/VedicMaths_Full.html`.

### Key Aesthetic Principles
- **Color Palette**: Use CSS variables defined in `:root`.
- **Typography**: Primary font is 'Nunito', 'Poppins' for headers.
- **Dark Mode (Games)**: Use gradient backgrounds for immersion (`linear-gradient(135deg, ...)`, dark base `#0F172A`).
- **Cards**: Compact, rounded corners (`rounded-[16px]`), subtle interaction feedback (hover effects).
